## Оплата через СБП (Система Быстрых Платежей)

В лендинг интегрирован официальный QR-код Системы Быстрых Платежей фонда «Дети-лучики» (банк-эквайер ВТБ `bank=100000000013`):
`https://qr.nspk.ru/AS1A004188F9QISE87DONIOS3GADGKH3?type=01&bank=100000000013&crc=1115`

### 💡 Почему мобильный банк предлагает ввести сумму:
1. **Статический QR-код фонда (`type=01`)**: данный идентификатор зарегистрирован банком ВТБ в реестре НСПК как **благотворительный статический код с открытой суммой** (свободное пожертвование).
2. **Безопасность банковских приложений**: когда приложение банка (Сбербанк, Т-Банк, ВТБ, Альфа-Банк) открывает ссылку СБП, оно обращается к серверу НСПК по ID `AS1A004188F9QISE87DONIOS3GADGKH3`. Ответ НСПК сообщает: «Получатель: КРОО ДЕТИ-ЛУЧИКИ, сумма не зафиксирована». В целях безопасности банк игнорирует сторонние query-параметры из браузера и просит самого плательщика указать сумму перевода.

### 🚀 Как это решено в интерфейсе для максимального удобства сотрудников Ozon:
1. **Кнопка «Скопировать сумму»**: рядом с выбранной суммой (например, 1 000 ₽) размещена кнопка быстрого копирования в буфер обмена.
2. **Прямой переход в банк**: по нажатию синей кнопки **«Перейти к оплате в банк через СБП»** на смартфоне автоматически открывается приложение банка со всеми реквизитами фонда.
3. **QR-код для ПК**: на экране компьютера отображается QR-код, который сотрудник сканирует камерой телефона.
4. **Фиксация в рейтинге Ozon**: кнопка **«Я перевёл [1 000 ₽] — добавить в рейтинг команды!»** сразу засчитывает вклад в турнирную таблицу Ozon и открывает скачивание именной открытки.

*(Примечание: для того чтобы сумма подставлялась банком строго без ручного ввода, на стороне фонда подключается шлюз динамических QR-кодов `type=02` через API банка/эквайера, например CloudPayments, Mixplat или VTB API).*

## Инструкция по развёртыванию на deti-luchiki.ru

### Вариант 1: Вложенная папка на сайте (Рекомендуемый)
1. Подключитесь к хостингу сайта `deti-luchiki.ru` по FTP или через файловый менеджер панели управления.
2. В корневой директории сайта (`public_html` или `www`) создайте папку `ozon`.
3. Загрузите в неё содержимое папки `deti-luchiki-ozon`.
4. Страница сбора будет доступна по адресу:  
   `https://deti-luchiki.ru/ozon`

### Вариант 2: Отдельный субдомен
1. В панели управления DNS домена `deti-luchiki.ru` добавьте запись:  
   `ozon` типа `A` (на IP-адрес сервера) или `CNAME` (на `deti-luchiki.ru`).
2. В веб-сервере (Nginx/Apache) настройте виртуальный хост с корневой директорией `deti-luchiki-ozon`.
3. Страница будет доступна по адресу:  
   `https://ozon.deti-luchiki.ru`

## Инструкция для координатора Ozon

1. **Доступ к статистике**:
   - Нажмите кнопку **«Статистика сбора»** в шапке сайта или перейдите по ссылке `https://deti-luchiki.ru/ozon?view=stats`.
2. **Метрики в реальном времени**:
   - Собранная сумма (₽).
   - Количество пожертвований и уникальных жертвователей.
   - Количество уникальных посетителей (Unique Visitors).
   - Общее число просмотров (Pageviews).
   - Рейтинг подразделений Ozon.
3. **Выгрузка отчёта**:
   - Нажмите кнопку **«Скачать отчёт в Excel (CSV)»**.
   - Скачивается файл `.csv` с кодировкой UTF-8 BOM, который открывается в Microsoft Excel без искажения русских букв и содержит полный журнал транзакций (ID, дата, имя, подразделение, сумма).
